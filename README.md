# BREAKPOINT / Pocket Sentinel

**Observe. Seal. Verify.**

An experimental AI-agent security prototype developed under Sandbox Memory's Mad Lab.

## Mission

Explore how autonomous agent actions can be observed, evaluated, denied, contained, and recorded for forensic review.

## Development Milestones

- v0.1 — Simulated security event reporting
- v0.2 — Rule-based policy detection
- v0.3 — Simulated agent containment
- v0.4 — Controlled file-write enforcement
- v0.5 — SHA-256 evidence recorder
- v0.6 — Independent integrity watchdog

## Verified Experiments

- Detected unauthorized simulated actions
- Identified and patched a path traversal weakness
- Denied unauthorized file writes
- Halted subsequent simulated agent actions
- Detected modified forensic evidence
- Successfully verified regenerated clean evidence

## Technology

Python 3.13.13, Termux, Android.

Developed on Steamrunner-B using a mobile keyboard.

## AI Development Acknowledgment

The Python implementation was generated by OpenAI's ChatGPT.

The project owner directed the research, selected the experiments, executed the code, examined results, and guided development.

This project demonstrates human-directed, AI-assisted security prototyping.

## Current Limitations

This is a controlled experimental prototype, not a production security system.

It does not yet monitor external AI agents, enforce operating-system-wide containment, or provide tamper-resistant evidence storage.

The watchdog checks locally stored evidence against a locally stored SHA-256 fingerprint.

## Future Research

Agent runtime integration, independent monitoring, stronger evidence integrity, and containment verification.
